Scope is the endpoint table in `GreenWay_Backend_Master_Spec_v1.md` (185 method/path rows). Old dealer/vendor routes are excluded. Counts treat an HTTP method plus path as one target.

| Classification            | Count | Coverage                                                                                                                                                                                                                                                                                       |
| ------------------------- | ----: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Implemented               |   183 | Health/auth including privileged staff MFA, market/catalog/public inventory, guest leads, customer accounts, inventory/source/media/admin, CRM/commercial workflows including customer-safe PDF generation/retrieval, dashboard/reports/audit, RBAC, CMS, notifications, and JSON/CSV imports. |
| Intentionally deferred    |     0 | No endpoint rows from the Master Spec table are currently deferred.                                                                                                                                                                                                                            |

Endpoint rows map to `openapi/openapi.yaml`; validation passes. The spec’s report lists paths rather than separate methods where an endpoint supports multiple methods, while this audit counts each method/path row. Additional implementation routes may appear in OpenAPI beyond the Master Spec table.
